# Richard Sesay — Personal Website

A responsive static personal website designed for GitHub Pages.

## Files
- `index.html` — website content and navigation
- `styles.css` — responsive styling
- `cv/Richard_Sesay_CV.pdf` — add your actual CV PDF here

## Before publishing
1. Add your latest CV PDF to the `cv` folder and name it exactly `Richard_Sesay_CV.pdf`.
2. Replace the generic GitHub link in `index.html` with your actual GitHub profile URL.
3. Add your actual ResearchGate profile URL.
4. Review the biography, education dates, publication titles, and consulting services.
5. Update the Estonian Green Movement portfolio entry with your exact role, activities, dates, deliverables, and verified outcomes. The current text is a cautious placeholder, not a claim of completed work.
6. Add a professional headshot or project images only if you want them; the current design does not require image files.

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, and the `cv` folder to the root of your GitHub repository.
2. Commit the files to your default branch (usually `main`).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your default branch and `/ (root)`, then click **Save**.
6. Wait for deployment and open the URL shown in the Pages settings.

The expected URL format is `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
